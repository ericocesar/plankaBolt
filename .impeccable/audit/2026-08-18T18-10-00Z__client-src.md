# Impeccable Technical Audit: client/src

## Score: 8 / 20

| Dimension | Score | Key Finding |
|---|---|---|
| Accessibility | 1/4 | Zero landmarks, zero aria-labels, zero live regions across entire app |
| Performance | 2/4 | 57 files use transition:all; 55 lack reduced-motion guard. 1,990 !important |

| Anti-Patterns | 2/4 | Oswald display font leaked into 10 body/label contexts. 35 gradients outside Login/Support |

## P0 -- Must Fix

1. **Zero semantic landmarks** (Accessibility)
   - No `<header>`, `<main>`, `<nav>`, `<footer>`, `<aside>` in any JSX file
   - WCAG 2.1 SC 1.3.1 failure

2. **Zero aria-label/aria-labelledby** (Accessibility)
   - 62 interactive elements (38 buttons, 8 links, 8 inputs) rely solely on inner text
   - WCAG 2.1 SC 4.1.2 failure

3. **Zero aria-live regions** (Accessibility)
   - Toasts, loading states, form validation, real-time updates invisible to assistive tech
   - WCAG 2.1 SC 4.1.3 failure

4. **93% SCSS files lack responsive breakpoints** (Responsive)
   - 189/203 SCSS files have no @media query
   - 8 fixed px widths >300px (CardModal 880/980px, BoardSettingsModal 800px, etc.)

## P1 -- Should Fix

5. **556 hard-coded hex colors in 142 files** (Theming)
   - Top offenders: AdministrationModal (17), CardModal (15), UserSettingsModal (15)
   - Dark/light theme switching impossible

6. **1,990 !important declarations across 79 files** (Theming)
   - Top: UserSettingsModal (142), AdministrationModal (134), styles.module.scss (117)

7. **9 interactive elements with height < 44px** (Accessibility)
   - Worst: 20px (BoardActions/RightSide, NotificationsStep/Item, Boards/Item)

8. **90/95 animated SCSS files lack prefers-reduced-motion guard** (Accessibility)

## P2 -- Nice to Fix

9. **Oswald display font in 10 non-heading contexts** (Anti-Patterns)
   - Card names (15px), tab items, 12px body text, webhook items

10. **5 outline:none/0 occurrences** (Theming)

## Systemic Patterns

- Semantic UI override arms race (1,990 !important)
- Token adoption binary: accent 138, all others <10
- Accessibility not a design consideration
- Responsive only via modal max-width:95vw
- 166 unique hex values across 142 files
- Oswald treated as universal font

## Strategy: Restrained

- Neutral surfaces stay blue-gray (hue 240) -- unchanged
- Accent IS the logo gold (H:80) -- `#F8B820` from eagle beak
- Accent on dark surface: gold text on blue-gray, or gold bg with dark text on buttons
- Error slightly warm (H:25) -- human-feeling against cool surfaces
- Warning close to accent (H:75) -- differentiate via lightness/chroma
